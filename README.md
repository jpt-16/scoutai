# ScoutCard AI

Upload your weekly Hudl breakdown CSV and get vector scout team cards, which you can swipe
through on an iPad at practice or print 2 or 4 to a page.

```bash
npm install
npm run dev   # http://localhost:3000, then click "Load demo script"
npm test
```

See [CLAUDE.md](./CLAUDE.md) for architecture, the Hudl column mapping, offline/PWA notes,
and Vercel deployment.
